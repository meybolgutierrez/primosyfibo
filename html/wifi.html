📡 Sistema Inteligente de Optimización WiFi

Aplicación de números primos para reducir interferencias y mejorar redes inalámbricas

🌍 Problema real

En edificios, oficinas y hogares existen muchas redes WiFi funcionando al mismo tiempo. Cuando varias redes usan los mismos canales, aparece interferencia y el internet se vuelve lento. Este sistema utiliza números primos como modelo matemático para recomendar canales menos repetitivos y reducir saturación.

🔢 Código fuente: verificación de números primos

La siguiente función es la que implementa la lógica de números primos dentro del sistema de optimización WiFi:

Función para determinar si un canal (o número) es primo

function esPrimo(numero) {
  if (numero <= 1) return false;
  for (let i = 2; i < numero; i++) {
    if (numero % i == 0) return false;
  }
  return true;
}

🔹 Explicación: La función recibe un número (canal WiFi) y verifica si es divisible solo por 1 y por sí mismo. Los canales primos (2,3,5,7,11,13,17,19) tienen menos interferencia porque se solapan menos con canales pares o múltiplos. El sistema los recomienda automáticamente.

Ejemplo de uso integrado

const canalActual = 6;
if (esPrimo(canalActual)) {
  console.log("Canal primo, buena elección");
} else {
  console.log("Canal no primo, se recomienda cambiar a 7, 11 o 13");
}

🔹 En la práctica, el sistema analiza el canal actual, calcula todos los canales primos hasta 20 y recomienda el mejor según la interferencia.
