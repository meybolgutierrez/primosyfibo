📜 Código fuente: Serie de Fibonacci aplicada al crecimiento

La siguiente función implementa la lógica de Fibonacci para proyectar la población año a año:

Función que genera la secuencia de Fibonacci

function generarFibonacci(terminos) {
  if (terminos <= 0) return [];
  if (terminos === 1) return [1];
  let serie = [1, 1];
  for (let i = 2; i < terminos; i++) {
    serie.push(serie[i-1] + serie[i-2]);
  }
  return serie;
}

🔹 Explicación: La función recibe la cantidad de años y devuelve la serie de Fibonacci (1, 1, 2, 3, 5, 8...). Cada número representa el factor de crecimiento respecto al año anterior. Luego se multiplica por un factor base para obtener el incremento poblacional real.

Ejemplo de uso integrado

const anios = 8;
const fibonacci = generarFibonacci(anios);
// fibonacci = [1, 1, 2, 3, 5, 8, 13, 21]
// La población en el año n = población inicial * suma de los primeros n factores
