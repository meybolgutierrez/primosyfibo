El desafío del agua en Bolivia

En La Paz y el Altiplano, la escasez de agua y el racionamiento afectan a miles de familias. El desperdicio y la falta de previsión agravan la situación.

Este sistema usa Fibonacci para proyectar el crecimiento del consumo y números primos para detectar alertas tempranas.

Secuencia Fibonacci:
1, 1, 2, 3, 5, 8, 13...
Números primos:
2, 3, 5, 7, 11, 13, 17, 19, 23...
¿Qué es un primo?Solo divisible entre 1 y sí mismo
Ver explicación detallada del algoritmo

Fibonacci modela el aumento diario del consumo (día1: base, día2: base, día3: suma de los dos anteriores...). Números primos señalan días o consumos "críticos" (posibles fugas o derroches). Se proyecta la duración del agua almacenada y se recomienda ahorro.

Datos de entrada

Ej: una familia de 4 gasta entre 150-300 L/día
Fibonacci: crecimiento progresivo del consumo (día 1: base, día 2: base, día 3: suma...)
Números primos: si algún consumo diario es primo → alerta de consumo atípico.

📜 Código fuente: Fibonacci y Números Primos

Las siguientes funciones son las que implementan la lógica matemática dentro del sistema:

1. Función para generar la serie de Fibonacci (crecimiento del consumo)

function generarSerieFibonacci(base, dias) {
  if (dias <= 0) return [];
  if (dias === 1) return [base];
  let serie = [base, base];
  for (let i = 2; i < dias; i++) {
    let siguiente = serie[i-1] + serie[i-2];
    serie.push(siguiente);
  }
  return serie.slice(0, dias);
}

🔹 Explicación: Recibe el consumo base (litros/día) y la cantidad de días. Devuelve un arreglo donde cada día el consumo es la suma de los dos días anteriores (crecimiento Fibonacci).

2. Función para verificar si un número es primo (alerta de consumo anómalo)

function esPrimo(num) {
  if (num < 2) return false;
  if (num === 2) return true;
  if (num % 2 === 0) return false;
  for (let i = 3; i <= Math.sqrt(num); i += 2) {
    if (num % i === 0) return false;
  }
  return true;
}

🔹 Explicación: Evalúa si un número es primo. Detecta consumos diarios que sean primos y genera alertas de posibles fugas o derroches.

3. Ejemplo de uso integrado

// Generar consumos para 15 días con base 180 litros
const consumos = generarSerieFibonacci(180, 15);
// Verificar si el consumo del día 5 es primo
if (esPrimo(Math.round(consumos[4]))) {
  alert("Consumo primo detectado, revisar fuga");
}

🔹 El sistema calcula todos los consumos, resalta los días primos y muestra una alerta visual.
